Narrative Measure Idioms

The four patterns behind any measure-driven text panel — print for PR review. Specimen: Measures - Narrative.tmdl + narrativePanel/visual.json.

1 · The clause pipeline

guarded ingredient  →  clause  →  filtered join
[Sales vs X %]         IF(ISBLANK(_p), "",        CONCATENATEX(
  BLANK unless           "down " & FORMAT(ABS(_p),   FILTER(UNION(ROW(…),ROW(…)),
  base > 0               "0.0%") & " vs X")            [@txt] <> ""),
                                                    [@txt], ", ", [@ord], ASC)

DAX's ", ".join(x for x in parts if x). Blank ingredient → empty clause → dropped by FILTER → shorter sentence. Nothing invents a number; nothing errors.

2 · Gates (line/panel visibility — always in the TMDL, never in the report JSON)

GateFires whenEffect
NOT HASONEVALUE('Market'[Currency])Market cleared / multi Panel blank — never sum mixed currencies
HASONEVALUE('Channel'[channel])Single channel sliced Channel line dropped (headline already reflects it)
Redundancy (top channel ≈ all revenue)Single-channel markets Channel line dropped — would restate headline
FY-grain checkGrain = FY One "vs LFY" clause (PP = LY at FY grain)
IF(_body <> "", _body)Everything suppressed Measure returns true BLANK, not ""

4 · Formatting idioms

IdiomShape
Directional words, not signs IF(_p < 0, "down ", "up ") & FORMAT(ABS(_p), "0.0%")
Multiples for extreme ratios actual ≥ ~3× budget → FORMAT(_ratio, "0.0") & "× budget"
Currency symbol per market SWITCH(SELECTEDVALUE('Market'[Currency]), "GBP","£", "EUR","€", "USD","$", "")
Icons UNICHAR(128200)=📈 UNICHAR(128201)=📉 — full code point only; surrogate pairs are rejected
Line breaks UNICHAR(10) in measures; textbox paragraphs render breaks — one bound measure per paragraph
