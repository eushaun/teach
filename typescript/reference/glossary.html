TypeScript Glossary

Terms as used in this workspace. Python anchors in grey. Grows with each lesson.

TypeScript (TS)
A language that adds a static type system on top of JavaScript. Every valid JavaScript program is also valid TypeScript; TypeScript adds type annotations and compile-time checking, then compiles down to plain JavaScript.
JavaScript (JS)
The language that actually runs — in browsers and in Node.js. TypeScript never runs directly; it always becomes JavaScript first. Think of JS as TypeScript's runtime form.
Compile time vs runtime Python: mypy check vs python run
Compile time is when the TypeScript compiler checks your types and translates your code. Runtime is when the resulting JavaScript executes. Type errors are caught at compile time — before the code ever runs. Python's closest equivalent is running mypy before python, except in TypeScript the check is not optional.
Compiler (tsc)
The TypeScript compiler. It does two jobs: (1) checks types and reports errors, (2) erases the types and emits plain JavaScript. Inside editors and the Playground, the same engine powers the red squiggles.
Type annotation Python: type hint
The : type after a variable or parameter name — count: number. Looks like a Python type hint, but it is enforced: violating it is a compile error, not a suggestion.
Type inference
The compiler working out a type you didn't write. const name = "orders" gives name the type string with no annotation needed. Idiomatic TypeScript annotates function signatures and lets inference handle local variables.
Type error
A compile-time complaint that values and types don't line up, e.g. "Argument of type 'string' is not assignable to parameter of type 'number'". Read it backwards: what was expected, what was given.
const / let Python: plain assignment
The two ways to declare a variable. const cannot be reassigned; let can. Python has no equivalent distinction — default to const and reach for let only when reassignment is the point.
Template literal Python: f-string
A backtick string with ${expression} holes: `Loaded ${n} rows`. TypeScript's f-string.
TypeScript Playground
The official in-browser editor at typescriptlang.org/play. Type-checks as you type and can run the compiled JavaScript — no installation needed.
Array Python: list
The ordered, mutable collection. Typed as string[], number[], etc. — element type then square brackets. No negative indexing: use xs.at(-1) for the last element.
Object literal Python: TypedDict / dataclass instance
Braces with key–value pairs: { table: "users", rows: 5 }. Looks like a Python dict, but has fixed, known, individually-typed fields, accessed with dot notation (sync.table) and typo-checked by the compiler. For genuine arbitrary-key dictionaries TypeScript uses Record or Map (later lesson).
Property Python: key / attribute
A named field of an object — its name plus its type. rowsLoaded: number is a property of TableSync.
Optional property (?) Python: NotRequired / Optional field
A property marked name?: type may be absent from the object. Reading it yields type | undefined, which the compiler makes you handle before use.
Type alias (type) Python: TypedDict class / type statement
A reusable name for a type: type TableSync = { table: string; rowsLoaded: number };. Purely a name — it creates no runtime class, and two aliases for the same shape are interchangeable.
for...of Python: for x in xs
The value-iterating loop: for (const t of tables) { }. Beware its sibling for...in, which iterates indices/keys, not values.
Union type (|) Python: X | Y in hints
A type that is one of several possibilities: string | undefined means "a string, or undefined." Teased in Lesson 2; taught properly in a future lesson.
Node.js
A program that runs JavaScript outside the browser — the JS equivalent of the python interpreter on your machine. MCP servers run on Node. We set it up in a later lesson.
